# 微信分享与海报

在「日历」选择日期，点「分享」，可切换「每日精选」与「极简语录」。模板仅使用日期、主题、历法和原创或已授权的短句。个人偏好中的星座、账号和日程不会用于生成公开内容。

登录后点「创建公开分享」，再点「分享给微信好友」，或从微信右上角菜单选择分享到朋友圈。好友进入独立落地页，朋友圈打开分享页的公开模式。链接有效七天。匿名打开不要求转发。访问仅记入口和时间。

点击「生成海报」可在 Canvas 中生成图片，再按需申请相册权限。已创建公开分享并且微信侧已配置时，生成海报会尝试加载官方小程序码。无法取得小程序码时，海报明确显示开发占位。

## 真机配置与核对

- 小程序端和服务端需使用同一个真实 AppID。AppSecret 只在服务端。微信后台配置 `request` 和 `downloadFile` 合法 HTTPS 域名。
- 后端 `WECHAT_CODE_ENV=release` 使用正式版并检查页面路径。开发联调可配置 `develop` 或 `trial`，微信账号需要对应版本访问权限。小程序码指向 `pages/share-landing/index`。
- 验证好友打开、朋友圈单页展示、扫码、同意或拒绝相册权限、用户退出后打开、过期链接与占位导出。当前真实微信过程仍待真机核对。
