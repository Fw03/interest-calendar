# 测试与微信提审清单

## 自动化

| 层 | 命令 | 覆盖 |
|---|---|---|
| 小程序 | `npm run typecheck`、`npm test` | 打包结构、日期与农历、主题和兴趣顺序、备注隔离、缓存与账号隔离、同步冲突、分享入口、Canvas 占位导出 |
| 后端 | `mvn test`、`mvn package` | Flyway 迁移、REST 契约、鉴权与双账号隔离、Redis 故障降级、分享白名单、举报、反馈、账号删除 |
| 运维 | `bash -n deploy/backup.sh 与 bash -n deploy/restore.sh` | 脚本语法检查，运行环境另行演练 |

H2 的 MySQL 兼容模式执行后端测试迁移。微信身份和 Redis 不可用由测试桩模拟。客户端同步和 Canvas 的测试使用 wx 接口桩。另用微信开发者工具 2.02.2608050 安装包内的 wcc、wcsc 编译全部 WXML 和 WXSS。实际验证状态见 [开发进度](../IMPLEMENTATION_STATUS.md)。
