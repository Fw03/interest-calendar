# 账号与同步

小程序默认使用本机 Storage。配置 API 后可匿名读取公共内容，微信登录由用户从「我的」主动触发。真实登录需要自己的小程序 AppID、后台服务和服务端 AppSecret。登录前的本机数据与各个微信账号的缓存分别保存。

## 本机记录迁移

1. 登录后在「我的」执行同步。
2. 选择「导入本机记录」，核对目标为当前微信账号后确认。
3. 日期和日程 ID 保持不变，重复导入时跳过已存在的 ID。只有云端尚未修改过偏好时才导入本机主题、星座和兴趣顺序。离线访客的原始数据保留当前设备上。

## 离线编辑和冲突

登录后每次写入先把变更保存到本机，再按顺序发送。重进小程序、网络恢复或点击「同步」均可重试。登录令牌失效时可用原微信账号重新登录并继续重试。退出账号后，界面显示离线访客的数据。

版本冲突时暂停该账号的队列。在「我的」选择「保留本机修改」会先拉取服务端数据，再将本机待同步修改应用到最新版本。确认「使用云端版本」会丢弃该账号在这台设备上尚未同步的修改。

公共内容以日期缓存 5 分钟。接口超时后，优先使用已有公共缓存，其次使用标识清晰的内置内容。私人日程使用独立的登录接口。
